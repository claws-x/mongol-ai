# S2 Web Corpus

This directory stores source policy, short code-point observations, and derived statistics for the S2 semantic-glyph engine.

- `sources.json` is the reviewed crawl seed list. A source is evidence, never a sole authority.
- `schema.json` defines the observation bundle.
- `observations.json` is generated by the crawler and contains short Traditional Mongolian Unicode segments, not full articles.
- `stats.json` contains reproducible counts derived from those observations.

Run:

```bash
npm run crawl:s2
npm run stats:s2
```

Every crawl rechecks `robots.txt`, identifies itself, follows redirects, accepts HTML only, waits at least 500 ms between requests, and records the final URL and content hash. Unknown-license pages remain `redistributable: false`; full HTML and full articles must not be committed.

Screenshots are not corpus data. The retained facts are exact code points, controls, limited context, URL, timestamp, and hash.
