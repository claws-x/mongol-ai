# 旧调研材料使用说明

`docs/04-research/` 中除当前索引、证据规则、覆盖报告和
`data/knowledge/` 事实源之外的早期文档，大多创建于 2026-04-03。

这些材料可以作为“曾经调研过什么”的线索，但不得直接用于：

- 对外产品声明；
- 专家联系；
- 训练数据选择；
- 准确率、兼容性和市场结论；
- “全球首个”“全部完成”等排他性声明。

发现以下任一情况时，必须回到原始来源重新核验：

- 没有可点击来源；
- 使用约数 Stars、下载量或市场份额；
- 出现 `xxx`、全零标识符、待创建等占位符；
- 声称所有浏览器“完全支持”；
- 把 SVG、旋转或 `text-orientation: upright` 当作通用蒙古文方案；
- 人物、邮箱、机构、论文无法在官方页面或正式论文库确认。

历史材料不会被静默删除；被新事实源取代的结论应保留废止说明，确保变更可追溯。
