# Phase K0 覆盖报告

**日期**：2026-08-08
**性质**：首轮可信基线，不是全球穷尽清单

## 已覆盖

- Unicode 17.0、Unicode 蒙古文文档登记和 UTN #57 v4；
- W3C 蒙古文布局任务组、章程和布局需求；
- 内蒙古大学多语种人工智能重点实验室与蒙古学学院；
- 内蒙古师范大学蒙古文信息处理、机器翻译和语言智能团队；
- 中央民族大学民族语言智能实验室与国家语言资源中心协作体系；
- 蒙古国立大学一项印刷传统蒙古文 OCR 机构记录；
- Noto Mongolian 与 tugstugi 社区资源入口；
- 2016–2026 的 11 项代表性 NER、语料、翻译、生成、文化评测、OCR 和
  大模型研究。

## 明确未完成

1. 蒙古国科学院、蒙古科技大学及蒙古国政府数字化项目；
2. 内蒙古民族大学、呼和浩特民族学院等地方高校团队；
3. 日本、韩国、俄罗斯和欧美蒙古学/数字人文机构；
4. 中文核心期刊、硕博论文、国家项目、专利和标准工作组完整成员；
5. Menksoft 等商业产品的可复现能力、许可和互操作矩阵；
6. 传统蒙古文图书、报刊、古籍、口语、方言、OCR和手写数据资源总表；
7. 全部数据集的下载、哈希、许可证、Unicode纯度和母语审核；
8. 专家本人对本库人物角色和技术摘要的确认。

## 不能从本库推出的结论

- 不能说“全球所有机构和专家已经收集”；
- 不能根据未收录推断某人或某机构没有研究；
- 不能把论文报告的指标直接当作产品准确率；
- 不能把“公开仓库”自动解释为“数据可商用”；
- 不能把西里尔蒙古文模型直接称为传统蒙古文模型；
- 不能把技术文档当作母语和字形正确性证明。

## 下一轮优先级

### P0

- 获取并核验 TM-Bench、MC²、Lotus、CMHG 的实际数据与许可证；
- 建立蒙古国机构与研究者官方清单；
- 对现有 115 条词汇审核队列开展第一轮母语审核；
- 把 W3C gap analysis 转化为浏览器自动化测试项。

### P1

- 建立论文 DOI/BibTeX、作者消歧与机构关系；
- 建立公开数据集清单和可复现下载快照；
- 建立传统蒙古文 OCR、转换、分词、拼写和生成的统一评测协议。

### P2

- 接入搜索索引或图数据库；
- 建立专家确认和争议裁决工作流；
- 在得到许可后，构建面向产品的 RAG 检索层。
