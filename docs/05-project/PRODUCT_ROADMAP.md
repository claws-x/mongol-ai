# Mongol AI 产品路线图：Phase 0–2

**事实源状态**：当前有效路线图

**最后更新**：2026-07-20

**产品方向**：可信的传统蒙古文数字写作工作台

旧版路线图把预设对话、系统字体和历史 Demo 当作成熟能力，也包含已经
证伪的竖排方案。本文件取代旧版 v1/v2/v3 时间表；功能只有满足退出条件
后才可标记完成。

## 北极星用户任务

用户能够输入或粘贴传统蒙古文，在不破坏 Unicode 控制字符的情况下获得
正确的竖排预览、编码级提示，并安全复制或导出原始文本。

## Phase 0 — 可信基础

### 目标

证明产品不会在最基础的显示、编码、安全和声明层面误导用户。

### 已交付

- 唯一正式入口与 Labs 隔离；
- Mongol AI Vertical Engine 2.0；
- `vertical-lr + mixed` 主路径及实测兼容回退；
- 自托管 Noto Sans Mongolian v3.002；
- Unicode 17.0 编码基线与审核记录结构；
- 安全 DOM 输出、语义键盘、CI 和自动化测试；
- Blink 与 Safari/WebKit 桌面竖排实机验证；
- Python 文本规范化保留 FVS、MVS 与 NNBSP。

### 退出条件

- [x] 自动化测试与 CI 通过；
- [x] 正式体验不使用整段 `upright`、旋转或逐字 DOM；
- [x] 动态消息、输入框和预览共享一个渲染契约；
- [x] Blink 与 WebKit 桌面竖排连写及左→右换列通过；
- [ ] Firefox/Gecko 桌面验证；
- [ ] iOS Safari 与 Android Chrome 实机验证；
- [ ] 至少 3 位独立母语/文字专家完成第一轮字形与用法审核。

Phase 0 的工程门槛已完成；设备与专家门槛仍为外部阻塞项，不能伪造完成。

## Phase 1 — 可用写作工作台

### 目标

从展示型 Demo 升级为可以完成一篇短文本的本地优先工作台。

### 本轮交付

- [x] 输入内容实时同步到独立竖排预览；
- [x] 码位、词组、蒙古文字符和格式控制符统计；
- [x] 草稿自动保存在当前浏览器；
- [x] 原始 Unicode 文本复制；
- [x] UTF-8 `.txt` 导出；
- [x] 虚拟键盘、物理输入、退格和规则实验记录共存；
- [x] 所有输出继续使用 `textContent`。

### 后续退出条件

- [ ] 导入 UTF-8 文本；
- [ ] 多草稿列表、重命名和删除恢复机制；
- [ ] 打印/PDF 版式原型；
- [ ] PWA 离线安装与更新策略；
- [ ] 移动端长文输入、选择和导出实机通过。

## Phase 2 — 可解释文本辅助

### 目标

提供有来源、有边界、可复现的编码和文字辅助，不把规则提示包装成 AI
正确答案。

### 本轮交付

- [x] 独立 `MongolianTextInspector`；
- [x] 孤立 FVS、U+FFFD 和规范化变化诊断；
- [x] FVS/MVS/NNBSP/ZWJ/ZWNJ 统计；
- [x] 与 112 条 Unicode 编码基线实时匹配；
- [x] 编码结论与字形/语言审核状态分开显示；
- [x] 诊断不修改原文。

### 后续退出条件

- [ ] 每条提示可展开来源、码位和上下文；
- [ ] 专家审核后的词条才能进入拼写/用法建议；
- [ ] 建立建议接受、忽略和误报反馈；
- [ ] 在版本化测试集上报告覆盖率、准确率和失败样例；
- [ ] 只有通过评估后才讨论翻译、生成或大模型功能。

## 明确不做

- 不手工替换词首、词中、词尾字形；
- 不把简化转写称为标准转写；
- 不把关键词回复称为 AI 对话；
- 不在缺少专家和数据集时声明拼写或语言正确；
- 不为了兼容旧浏览器牺牲文本选择、复制和无障碍。

## 成功指标

- 核心任务完成率：输入 → 预览 → 复制/导出；
- Unicode 控制字符往返保持率；
- 竖排引擎 `ready` 比例与降级原因；
- 诊断误报/漏报及专家复核结果；
- 草稿恢复成功率；
- 浏览器与设备矩阵的真实通过率。
