# Phase 0：可信产品基线

**状态**：工程基线完成；设备与专家验证进行中

**产品版本**：v5.2.0 Phase 0 baseline  
**事实源优先级**：本文件、根 README、自动化测试结果

## 产品定位

Mongol AI 当前是传统蒙古文输入、竖排预览和语言技术研究原型，不是成熟的大模型助手。

长期产品方向是“传统蒙古文智能写作工作台”：输入、转写、校验、竖排预览、纠错解释、复制与导出。

## Phase 0 目标

在扩展功能前建立可信、可复现的质量基线：

- 一个正式产品入口，其余演示明确归入 Labs。
- 正式体验全部采用原生竖排布局。
- 核心 Python 模块可导入并通过自动化测试。
- 用户输入不作为 HTML 注入页面。
- 核心输入流程具备基础键盘和读屏语义。
- 项目声明与实际能力一致。
- Unicode/FVS、浏览器兼容性和母语审核均有明确待验证状态。

## 声明规则

对外使用“正确”“兼容”“准确率”前，必须同时具备：

1. 有版本的数据集或测试语料。
2. 可在 CI 或明确环境中复现的评估脚本。
3. 原始结果与失败样例。
4. 适用范围和已知限制。
5. 涉及语言正确性时的母语或专家审核记录。

在条件不满足时，只能使用“原型”“实验”“待验证”等表述。

## Phase 0 退出条件

- 所有自动化测试通过。
- 正式入口无阻断级安全或无障碍问题。
- 标准语料与审核流程落库。
- 三个目标浏览器完成桌面与移动尺寸验证。
- README、首页和项目事实源没有未经证明的准确率或兼容性声明。

## 已知限制

- 当前对话仅为关键词规则。
- 词汇与短语数据规模小，且尚未完成系统性来源和审核标注。
- 自动化测试证明的是代码基线，不证明语言学正确性。
- 历史 Labs 页面尚未逐一迁移到正式体验的质量标准。
